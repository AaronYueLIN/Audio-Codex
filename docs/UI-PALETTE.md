# Audio Codex UI Palette — 1984 Toyota Truck 2P5

The application font stack is unchanged.

Reference:
- Toyota two-tone code: 2P5
- Toyota 033 White: screen reference `#E1DBC6`
- Toyota 137 Silver Metallic: screen reference `#93948D`

Important:
Automotive paint is a physical finish. Silver Metallic contains reflective metallic material, so no single RGB/HEX value can reproduce its appearance on a monitor. The UI therefore uses `#93948D` as the base and only lighter/darker neutral variants of the same silver family to suggest the metallic finish.

Artwork is not tinted, cropped, rounded, or recolored. Its original aspect ratio is preserved with `object-fit: contain` inside a consistent library artwork slot.
